Job Feed Pipeline

An unattended scraper that pulls every remote job posted to Indeed Canada in the last 24 hours, keeps them in one SQLite file, serves a dashboard, and writes a tailored resume on request.

Built on the accetto/debian-vnc-xfce-python-g3 Docker image, which provides the Debian + Xfce desktop, the always-on VNC display and Python that the scraper runs on.

4 pipeline steps 1 database file 06:00 daily run ~2 min to collect ids ~5 s per listing ~10 s per resume

The whole loop

The four steps

1 · browser_start.py · ~4 s

Start Chrome

  • Kills every Chrome process, then launches a fresh one with --remote-debugging-port=9222.
  • Uses a cloned profile, because Chrome 136+ refuses debugging on the default one. Cookies and logins came with the clone.
  • Waits for the window and the DevTools endpoint.
2 · login_indeed.py · ~3 s when signed in

Sign in to Indeed

  • Opens ca.indeed.com and reads the header: a My jobs link means signed in.
  • If not, opens the auth page and clicks the Google one-tap button with a real mouse click, found by image match.
  • Repeats until signed in. Anonymous visitors only get page 1 of results.
3 · get_job_ids.py · ~2 min for 10 pages

Collect job ids

  • Finds the page count by jumping to an absurd offset; Indeed clamps to the last page.
  • One page load and one DOM query per page: every card's 16-hex key, title, company, pay, and any paid-ad link.
  • Upserts into job_ids; a job seen again keeps its first_seen, archive flag and resume.
4 · get_job_listings.py · ~5 s per job

Fetch listings

  • Visits viewjob?jk=… for every key without a saved listing.
  • Captures title, company, the "Job details" block, the full description, and the apply link.
  • Status per row: ok, expired, blocked or error. Blocked stops the run for a human look.
